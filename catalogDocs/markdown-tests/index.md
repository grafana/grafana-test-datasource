These pages exist to test how plugin docs render. Each page covers one group of Markdown features, and every case sits under its own heading so a test can link straight to it.

## Pages

- [Text formatting](./text-formatting.md) - headings, emphasis, lists, quotes and footnotes
- [Tables](./tables.md) - alignment, inline markup and line breaks in cells
- [Code blocks](./code-blocks.md) - highlighted languages, unknown languages and inline code
- [Links](./links.md) - relative, anchor, external and reference-style links
- [Images and videos](./images-and-videos.md) - images, YouTube embeds and short videos
- [Callouts](./callouts.md) - the five callout types and plain quotes
- [Collapsible sections](./collapsible.md) - closed, open and nested details blocks
- [Nested page](./nested/page.md) - a page in a subfolder, used for relative link and image checks
